# Portfolio Assets Guide

Drop your files in the folders below. The website will automatically pick them up.

## Folder Structure

```
assets/
├── resume/
│   └── Harshil_Patel_Resume.pdf    ← Your resume PDF
├── profile/
│   └── profile.jpg                  ← Profile photo (square, min 400x400px)
├── projects/
│   ├── ai-cfo/
│   │   ├── hero.png                 ← Main project banner
│   │   ├── dashboard.png            ← Dashboard screenshots
│   │   ├── architecture.png         ← System architecture diagram
│   │   └── workflow.png             ← ML/data pipeline diagram
│   ├── healthvitals/
│   │   ├── hero.png

    └── ...
```

## Image Recommendations
- **Profile photo**: Square (400x400+), professional headshot
- **Project images**: 1200x630px (OG image ratio) works great
- **Certificates**: Any size, will be auto-fitted
- **Resume**: PDF format
